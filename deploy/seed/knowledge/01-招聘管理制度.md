# 星云科技招聘管理制度

## 招聘基本原则

招聘应遵循公开、公平、岗位匹配和最小必要信息原则。招聘人员不得以性别、婚育状况、民族、宗教、籍贯等与岗位履职无直接关系的因素作为筛选条件。所有筛选结论必须能够追溯到岗位要求、候选人材料或面试记录。

## 候选人信息处理

候选人手机号、邮箱、身份证号等个人信息仅可用于招聘联络和背景核验。系统中展示和导出的联系方式应进行脱敏，未经候选人授权不得将简历转交给外部机构。候选人要求删除个人资料时，HR 应在三个工作日内发起删除流程。

## 简历筛选规范

简历筛选采用规则评分、项目语义匹配和人工复核结合的方式。系统未发现某项技能时，只能标记为“简历中未体现”，不得直接认定候选人不具备该能力。对于边界候选人、跨行业候选人和工作经历存在时间空档的候选人，应进入人工复核。

Java 后端岗位重点关注 Java 基础、Spring Boot、数据库设计、缓存和实际项目职责。前端岗位重点关注 Vue 或 React、TypeScript、组件化、性能优化和工程化。数据岗位重点关注 SQL、Python、指标体系、数据质量和业务理解。

## 招聘时效

收到简历后应在两个工作日内完成初筛。技术面试结束后，面试官应在当天提交评价。需要增加面试轮次时，应向候选人说明原因和预计时间。最终不录用的候选人原则上应在五个工作日内获得结果反馈。

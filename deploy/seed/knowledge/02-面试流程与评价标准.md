# 技术岗位面试流程与评价标准

## 面试流程

标准流程为简历初筛、HR 初访、技术一面、技术二面或交叉面、招聘负责人确认、Offer 审批。初级岗位通常安排一轮技术面，中高级岗位至少安排两轮技术面。涉及团队管理的岗位需要增加管理能力和跨团队协作评估。

## 技术评价维度

技术面试评价包括基础知识、项目深度、问题分析、工程质量、沟通协作和学习能力。面试官应记录候选人的具体回答和项目证据，避免只填写“感觉不错”“基础一般”等无法复核的结论。

项目深度重点判断候选人是否能够解释业务背景、个人职责、技术选型、关键难点、结果指标和复盘。候选人只描述团队成果但无法说明个人贡献时，应降低项目可信度并进一步追问。

## Java 后端面试建议

可以围绕 Spring Bean 生命周期、事务传播、MySQL 索引、慢查询分析、Redis 缓存一致性、消息幂等、接口限流和线上问题排查提问。三年以上候选人应能说明至少一个性能优化或稳定性治理案例。

## 前端面试建议

可以围绕 Vue 响应式原理、组件通信、TypeScript 类型设计、浏览器渲染、首屏性能、状态管理和前端工程化提问。候选人应能够解释实际项目中的性能指标或复杂交互实现。

## 评价等级

评价分为强烈推荐、推荐、待定和不推荐。待定必须写明需要补充验证的问题。不推荐必须基于岗位要求和面试事实，不得包含与岗位无关的主观评价。

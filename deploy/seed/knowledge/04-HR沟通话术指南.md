# HR 候选人沟通话术指南

## 初次联系

推荐表达：你好，我是星云科技招聘团队的 HR。我们正在招聘 Java 后端开发工程师，看到你的 Spring Boot 和电商系统项目经历与岗位比较匹配，想了解你近期是否考虑新的机会。

初次联系应说明公司或团队、岗位名称、关注到的候选人经历以及沟通目的。避免发送只有“在吗”“有兴趣吗”的无上下文消息。

## 询问求职意向

可以询问候选人关注的技术方向、工作地点、到岗周期和职业发展诉求。不要一次提出过多问题，优先围绕候选人最关心的信息展开。

## 面试邀约

面试邀约应包含岗位、面试形式、预计时长、可选时间和需要准备的内容。推荐表达：技术一面预计 60 分钟，采用线上视频方式，主要交流 Java 基础、数据库和你最近参与的项目。周三下午或周四上午是否方便？

## 延迟反馈

当内部流程延迟时，应主动说明当前进度和新的反馈时间。推荐表达：抱歉让你久等了，目前面试评价正在进行交叉确认，预计明天下午前给你明确反馈。

## 婉拒候选人

婉拒应保持尊重，不披露其他候选人的个人信息。可以说明本次岗位更侧重的能力方向，并感谢候选人的时间。不得使用侮辱、贬低或带有歧视含义的表述。
